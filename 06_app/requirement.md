# EDA Automation Requirement

## User
Business Analyst

## Problem
Business analysts spend time manually exploring datasets before analysis.

## Input CSV Format
The application accepts a CSV file containing sales or business data.

## Expected Outputs
- Dataset Shape
- Column Names
- Data Types
- Missing Value Summary
- Numeric Summary Statistics
- Top 10 Sales Records
- Histogram
- Bar Chart
- Correlation Heatmap

## Success Criteria
The application should automatically generate an Exploratory Data Analysis (EDA) report after the user uploads a CSV file.
