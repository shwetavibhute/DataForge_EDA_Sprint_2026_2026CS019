## 1. Problem Statement

The objective of this practical was to analyze the sales dataset using Microsoft Excel. I used formulas, Pivot Tables, charts, slicers and a dashboard to understand the sales performance.

## 2. Concept Elaborated

Excel provides useful tools for Exploratory Data Analysis (EDA). Summary statistics, Pivot Tables, charts and slicers help organize data, identify trends and present information in a simple and interactive way.

## 3. Execution Steps

- Opened the cleaned Excel dataset.
- Calculated Count, Sum, Average, Minimum, Maximum, Median and Standard Deviation using Excel formulas.
- Created Pivot Table 1 to analyze sales by Category and Segment.
- Created Pivot Table 2 to compare sales by Region.
- Created Pivot Table 3 to show the monthly sales trend.
- Added a Column Chart, Bar Chart and Line Chart.
- Inserted Category and Region slicers.
- Created a Dashboard with KPI cards, charts and labels.
- Saved the workbook as `p3_excel_eda_dashboard.xlsx`.

## 4. Key Insights

- Technology category generated higher sales than the other categories.
- Sales performance was different across regions.
- The dashboard made it easy to understand and compare the sales data.

## Report Questions

### 1. Which pivot table gave the most useful insight?

The Category and Segment Pivot Table gave the most useful insight because it clearly showed the sales performance of each product category across different customer segments.

### 2. What changed when you used slicers?

The slicers made the dashboard interactive. They helped me quickly filter the data by Category and Region and view only the required information.

### 3. What is one limitation of doing this only in Excel?

Excel is good for basic data analysis, but it becomes slow with large datasets and has fewer interactive features compared to tools like Power BI.
