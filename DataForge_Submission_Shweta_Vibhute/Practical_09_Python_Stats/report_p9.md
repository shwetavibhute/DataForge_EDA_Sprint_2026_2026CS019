### 1. Problem Statement

The objective of this practical was to perform Exploratory Data Analysis (EDA) using Python by generating descriptive statistics, creating grouped summary tables, ranking records based on a meaningful metric, and identifying statistical insights from the dataset.

### 2. Concept Elaborated

Exploratory Data Analysis (EDA) is the process of examining and summarizing data to understand its structure, patterns, and relationships. Python's Pandas library provides functions such as describe() for statistical summaries and groupby() for aggregating data by categories. Ranking tables help identify the highest and lowest values, while missing-value analysis helps assess data quality before further analysis or model building.

### 3. Execution Steps
1. Loaded the cleaned dataset into a Pandas DataFrame using Jupyter Notebook.
2. Generated descriptive statistics for numeric columns using the describe() function.
3. Calculated and exported the missing-value percentage table.
4. Created four grouped summary tables using the groupby() function.
5. Generated Top 10 and Bottom 10 ranking tables based on a selected metric.
6. Exported all generated tables and wrote insights based on the analysis.
### 4. Key Insights
* The descriptive statistics provided an overview of the numerical features in the dataset.
* Grouped tables revealed trends and comparisons across different categories.
* Ranking tables identified the highest and lowest values for the selected metric.
