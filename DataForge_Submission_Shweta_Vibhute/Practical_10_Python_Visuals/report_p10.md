## 1. Problem Statement

The objective of this practical was to perform Visual Exploratory Data Analysis (EDA) using Python by creating multiple data visualizations and developing an automated EDA application. The application loads a CSV dataset, performs data quality checks, generates statistical summaries and visualizations, and provides automated insights for data analysis.

## 2. Concept Elaborated

Visual Exploratory Data Analysis (EDA) helps understand the distribution, relationships, and patterns in a dataset through graphical representations. Charts such as histograms, boxplots, scatter plots, line charts, bar charts, correlation heatmaps, and missing-value visualizations make it easier to identify trends, outliers, and data quality issues. An automated EDA application simplifies this process by generating summaries, visualizations, and insights with minimal user effort, making data exploration faster and more efficient.
