# 📖 Project Overview

The **DataForge EDA Sprint 2026** is a comprehensive data analytics project that demonstrates the complete data analysis workflow using **Excel, Power BI, Python, Pandas, Matplotlib, and Streamlit**.

The project focuses on:

- Data Acquisition
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Dashboard Development
- Statistical Analysis
- Data Visualization
- Automated EDA Application Development
- GitHub Project Management

# ▶️ How to Run the Project

## Clone Repository

```bash
git clone https://github.com/shwetavibhute/DataForge_EDA_Sprint_2026_2026CS019.git
```

## Create Virtual Environment

```bash
python -m venv .venv
```

## Activate Environment

Windows

```bash
.\.venv\Scripts\activate
```

## Install Required Libraries

```bash
pip install pandas numpy matplotlib streamlit openpyxl jupyter
```

## Run Jupyter Notebook

```bash
jupyter notebook
```

## Run Streamlit App

```bash
cd 06_app
streamlit run app.py
```

Open in browser:

```
http://localhost:8501
```
